## 3. A.2 — Audit Konfigurasi Flutter & Siklus Hidup Runtime

### 3.1 Konfigurasi URL, Transport, & Topologi Fisik `CPH2127`
- **[`main.dart`](file:///c:/Users/hkur7/Documents/development/GPS%20Project/gpsku/lib/main.dart#L62-L67):** Membaca `String.fromEnvironment('API_BASE_URL', defaultValue: 'http://10.0.2.2:8082')` ke `AppConfig(baseUrl: configuredBaseUrl)` yang disuntikkan ke `DioClient`, `TraccarWebSocketService`, dan `TelemetryEmulatorRemoteDataSourceImpl`.
- **Perangkap Loopback pada Perangkat Fisik Android (`CPH2127`):**
  - Default `http://10.0.2.2:8082` **hanya** bekerja di dalam Android Emulator (AVD); pada perangkat fisik `CPH2127` (terbukti di log P9.3.4), `10.0.2.2` gagal terhubung dan mengalami `connectionTimeout` 15 detik.
  - Pada Android fisik, `127.0.0.1` merujuk pada **perangkat `CPH2127` itu sendiri**, bukan workstation Windows. Oleh karena itu koneksi lokal via USB **mutlak membutuhkan kedua hal**:
    1. `adb reverse tcp:8082 tcp:8082` aktif dan terverifikasi untuk `CPH2127`.
    2. Build/run Flutter menyertakan `--dart-define=API_BASE_URL=http://127.0.0.1:8082`.
- **Rantai Transport Aktual dengan Konfigurasi `API_BASE_URL=http://127.0.0.1:8082`:**
  1. **REST API (`DioClient`):** Menuju `http://127.0.0.1:8082/api/*` (via `adb reverse` $\rightarrow$ Docker `8082`).
  2. **WebSocket (`TraccarWebSocketService`):** [`AppConfig.webSocketUri`](file:///c:/Users/hkur7/Documents/development/GPS%20Project/gpsku/lib/core/config/app_config.dart#L20-L28) membentuk `ws://127.0.0.1:8082/api/socket` dengan header `Cookie: JSESSIONID=...` dari `SessionCookieJar`.
  3. **OsmAnd Telemetry (`TelemetryEmulatorRemoteDataSourceImpl`):**
     - Pertama mencoba direct `http://127.0.0.1:5055/` (karena `baseUrl` berskema `http://` dan tanpa override port). Port `5055` tidak dibuka di `CPH2127` maupun Docker $\rightarrow$ segera memicu `DioExceptionType.connectionError`.
     - [`_shouldAttemptHttpProxyFallback`](file:///c:/Users/hkur7/Documents/development/GPS%20Project/gpsku/lib/features/emulator/data/datasources/telemetry_emulator_remote_data_source.dart#L91-L110) memenuhi syarat (`!isHttps`, no custom host/port, `5055 != 8082`) dan langsung melakukan fallback ke **`POST http://127.0.0.1:8082/`** (`application/x-www-form-urlencoded`).
     - `OsmandTransportDiagnostics` mencatat `mode: OsmandTransportMode.httpWebProxyFallback`, `endpointUri: http://127.0.0.1:8082/`, serta `initialDirectFailureReason` (error `:5055` asal), dan status probe menjadi `OsmandPortStatus.reachableViaFallback` (**`Fallback :8082 Aktif`**).
