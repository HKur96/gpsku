   Pencegahan race condition menggunakan **Timestamp Sequence Guard** (`newPosition.fixTime > currentPosition.fixTime`), data cache lokal wajib diberi label *"Data Tersimpan / Last Known Data"*, dan eksekusi remote command dilarang keras saat offline.

   Tidak ada modifikasi apa pun pada kode sumber Java backend, database PostgreSQL, REST API, maupun WebSocket contract.
